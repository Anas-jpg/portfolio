# Portfolio concepts inspired by your references

Your references point toward a personal, artistic portfolio: light backgrounds, a memorable portrait, large black type, simple navigation, and a few organic accents. The new concepts use Muhammad Anas’s existing portrait and verified full-stack role. Template names, people, and company logos are not carried over.

## Ink & Code

Closest to the first reference. A grayscale portrait dissolves into muted teal, indigo, and ochre watercolor, with the introduction beside it. Crisp black actions and generous whitespace keep it professional. The About page can reuse a small painted portrait; Projects use clean screenshot spreads; Contact uses one restrained brush accent.

Best for an expressive personal identity. Limit watercolor to portrait edges so readability stays strong.

## Portrait Studio — recommended

Closest to the second reference. A grayscale cutout portrait sits in a sage arch above a large name and clear full-stack role. An elegant emerald line leads toward contact. The capabilities strip uses real skills instead of company logos. About keeps the portrait/arch motif; Projects use large image-led case studies; Contact uses a simple sage panel.

Best balance for recruiters and freelance clients: memorable, approachable, and easy to understand. On mobile, reduce portrait height and show the role and actions before the work section. Support reduced motion for any animated line.

## Shared implementation direction

Keep the prepared Next.js, React, TypeScript, Tailwind, and shadcn/ui foundation. The visual distinction comes from custom typography, portrait artwork, spacing, and composition. Core headings, navigation, links, and buttons will be live accessible HTML; generated mockups are concept references, not full-page website assets.

Use Home / About / Projects / Contact, with Resume, GitHub, and LinkedIn easy to reach. Keep case-study content factual. Do not add template client logos or availability claims. No Articles route is implied unless real articles are supplied.

These three previews were created with the built-in image generation tool. Exact prompts and provenance are stored beside each PNG. None is approved for implementation yet. The previous technical concepts remain preserved, while the portrait-led options are the active review set.
